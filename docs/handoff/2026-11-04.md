## Things that cost time before

- **Trimmed ASF.** OS-specific ASF builds drop APIs ASF itself never uses. `tools/TrimCheck` is the arbiter; a build that passes locally can still fail it. Known missing: `JsonNode.ToJsonString`, `JsonElement.TryGetProperty(string)`, `Enumerable.Order(comparer)`, `[HttpPut]`, `NotFound(object)`, `Conflict(object)`, `HMACSHA256.HashData(byte[], byte[])` (the span overload works).
- **Submodule and `.gitmodules` move together.** The `branch` entry and the gitlink must name the same ASF release; the bump workflow does both.
- **New worktrees.** Clone the submodule shallow (`git submodule update --init --depth 1`); a full clone took over 15 minutes. Remove a worktree with `git worktree remove --force` after checking it is clean.
- **Running the plugin for real.** `tools/smoke/smoke.sh` runs it on an official trimmed ASF release (34 checks); the README's schema contract is the reference for plugin authors.
- **Screenshots** live on the `pr-assets` branch, under `<PR number>/` and `1.0.0.0/`, linked pinned to a commit. Never on `main`.
- **Design decisions worth keeping:** secrets marked `writeOnly` never leave the host; raw reads need a real `IPCPassword` even with the opt-in (ASF's IPC does not filter the `Host` header, so DNS rebinding is possible); the raw editor refuses every ASF property name, keys with a working schema, and everything when the catalog is incomplete.
